# 🦊 Foxical — Английский с Лисёнком Люми

Мобильное веб-приложение (PWA) Foxical для интерактивного изучения английского языка в стиле Duolingo.
Проект создан в соответствии со всеми критериями оценки («Вайб-кодинг: Мобильные приложения — 10 класс»).

---

## 🌟 Ключевые Особенности

1. **Уникальный маскот и визуальный стиль:**
   - Вместо зелёной совы — обаятельный **Лисёнок Люми** (векторная SVG-анимация с живыми эмоциями: радость, удивление, грусть при ошибке, конфетти при победе).
   - Фирменная тёплая «закатная» цветовая палитра: неоновый мандарин (`#FF6F00`), космический ультрафиолет (`#7C4DFF`), изумрудный (`#00C853`) и золотой (`#FFB300`).
   - Фирменные 3D-кнопки Duolingo с тактильным эффектом нажатия.
   - Звуковой движок на Web Audio API (двухтоновый сигнал правильного ответа, победные фанфары, озвучка английских слов).

2. **Древо уровней и типы заданий:**
   - Извилистая дорожка уровней с разблокировкой по цепочке (Основы, Еда и напитки, Животные, Путешествия, Семья, а также финальный БОСС-уровень).
   - Интерактивные упражнения:
     - Выбор верного перевода (Multiple choice) с аудио-озвучкой;
     - Конструктор фраз из блоков слов (Word Bank builder);
     - Сопоставление пар карточек (Matching Pairs);
     - Проверка английского произношения.

3. **Геймификация и экономика:**
   - Жизни (5 сердечек, тратятся при ошибках);
   - Накопление опыта (XP) и кристаллов (Gems);
   - Ударный режим (Streak / Огонек дней подряд 🔥);
   - Магазин: покупка восстановления сердечек, заморозка удара, эликсиры опыта (+50 XP), зелье х2 наград за уроки (🧪);
   - Достижения (ачивки с трофеями).

4. **Архитектура, База данных и ИИ (Блок 3):**
   - **Авторизация и профили:** Изоляция пользователей (каждый аккаунт сохраняет свой личный прогресс, опыт и статистику).
   - **База данных:** Поддержка облачной базы **Supabase** (Create, Read, Update) с автоматическим оффлайн-fallback на локальное хранилище.
   - **ИИ API:** Вызов нейросети **Google Gemini 2.5 Flash** для объяснения ошибок («Почему здесь этот артикль?») и живого общения с лисёнком в его комнате и чате.

## 🚀 Как Запустить Проект

### Вариант 1. Локально на компьютере (Быстро)
Просто дважды кликните по файлу **`index.html`** в проводнике, и приложение откроется в вашем браузере!

### Вариант 2. Запуск на смартфоне через QR-код (Блок 4 — Деплой)
Чтобы открыть приложение на телефоне перед комиссией:

1. **Через GitHub Pages (Бесплатно, 1 минута):**
   - Загрузите папку проекта в свой репозиторий на GitHub.
   - В настройках репозитория (`Settings` → `Pages`) выберите ветку `main` и нажмите **Save**.
   - Ссылка на ваше приложение будет готова! Сгенерируйте для неё бесплатный QR-код на любом сайте (например, [qr-code-generator.com](https://www.qr-code-generator.com/)) и покажите учителю.

2. **Через Vercel / Netlify:**
   - Перетащите папку проекта в [app.netlify.com/drop](https://app.netlify.com/drop) или [vercel.com](https://vercel.com).
   - Получите мгновенную ссылку `.vercel.app` и открывайте на смартфоне.

## 📂 Структура Файлов

```
├── index.html            # Главный интерфейс приложения и модальные окна
├── css/
│   └── style.css         # Стили Duolingo-дизайна, 3D-кнопки, адаптивная верстка
├── js/
│   ├── mascot.js         # Векторный движок маскота Люми с эмоциями и скинами
│   ├── sound.js          # Web Audio API синтезатор звуков и Web Speech API
│   ├── data.js           # База уровней, упражнений, товаров магазина и ачивок
│   ├── auth.js           # Авторизация, изоляция профилей и интеграция Supabase
│   ├── ai.js             # Интеграция Gemini API и экспертная база грамматики
│   └── app.js            # Игровой цикл, логика уроков, квесты и конфетти
├── manifest.json         # PWA манифест для добавления на экран смартфона
├── PROJECT_DEFENSE.md    # Полная шпаргалка к защите на 100 баллов и речь питча
└── README.md             # Данный файл
```
