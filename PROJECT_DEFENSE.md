## 🎤 2. Готовая Речь для Питчинга (2-3 минуты)

> **Совет:** Говорите уверенно и держите телефон с открытым приложением в руках!

### Шаг 1: Проблема (30 секунд)
> «Здравствуйте! Большинство приложений для изучения английского языка либо перегружены скучной теорией, либо слишком однообразны. Тот же зелёный совёнок из Duolingo часто давит на чувство вины, а детям и подросткам хочется более тёплого, вовлекающего и отзывчивого наставника. 
> Мой проект — **Foxical**. Это мобильное приложение нового поколения с собственной тёплой закатной палитрой, харизматичным маскотом **Лисёнком Люми**, полноценной геймификацией и встроенным умным ИИ-репетитором.»

### Шаг 2: Демонстрация на телефоне (60 секунд)
*(В этот момент показываете экран телефона)*
> «Давайте посмотрим на приложение вживую:
> 1. **Авторизация и профили:** Данные строго разграничены. Если я войду под другим аккаунтом, прогресс будет изолирован. Также подключена синхронизация с облачной базой **Supabase**.
> 2. **Геймификация и уровни:** У нас есть интерактивная тропинка уровней. Каждый урок содержит разноплановые задания — выбор ответа, конструктор фраз из плиток, сопоставление пар и озвучку через речевой синтез.
> 3. **Реакции маскота:** При правильном ответе Люми празднует победу, звучит фирменный двухтоновый сигнал и взлетает конфетти. При ошибке списывается сердечко, а Люми грустит.
> 4. **ИИ-помощник:** Если я ошибаюсь, прямо в уроке доступна кнопка *"Спросить ИИ-Люми"*, которая вызывает нейросеть для понятного разбора грамматики. Также во вкладке "ИИ-Люми" есть живой чат для тренировки разговорного английского.
> 5. **Магазин и награды:** Заработанные кристаллы можно потратить на восстановление сердечек, заморозку ударного режима, эликсиры опыта и зелье х2 наград за следующий урок.»

### Шаг 3: Использованные технологии (30 секунд)
> «Проект разработан с чистой модульной архитектурой:
> • **Frontend / Mobile UI:** Адаптивный PWA-интерфейс, тактильные 3D-кнопки Duolingo, живая анимация маскота Люми, Web Audio API для звуков без задержек.
> • **База данных:** Supabase REST API с локальным fallback-хранилищем для полной отказоустойчивости.
> • **Искусственный Интеллект:** Интеграция API Google Gemini 2.5 Flash с педагогическим промптом, а также экспертная система грамматических правил.»

### Шаг 4: Чему научился (20 секунд)
> «В ходе работы по методологии вайб-кодинга я научился точно формулировать контекст для ИИ, разделять проект на независимые модули, проектировать клиент-серверную архитектуру, реализовывать авторизацию и разворачивать мобильные PWA в сети. Спасибо за внимание! Готов ответить на ваши вопросы.»

## ❓ 4. Ответы на Возможные Вопросы Жюри (5 баллов)

**Вопрос 1: «Почему вы выбрали PWA, а не нативный Android/iOS в Android Studio?»**
> **Ответ:** «PWA позволяет запустить приложение на любом смартфоне (как iOS, так и Android) мгновенно по одной ссылке или QR-коду без долгой модерации в App Store и Google Play. При этом пользователь получает полный опыт нативного приложения: полноэкранный режим, сохранение данных, тактильные звуки и работу в оффлайне.»

**Вопрос 2: «Что произойдет, если у пользователя пропадет интернет или кончится квота ИИ API?»**
> **Ответ:** «Архитектура спроектирована по принципу Graceful Degradation (элегантной деградации). Если нет подключения к Supabase или ИИ API, включается локальный модуль хранения и встроенная база правил грамматики. Приложение никогда не упадет с ошибкой и продолжит работать.»

**Вопрос 3: «Как обеспечивается разграничение данных разных пользователей?»**
> **Ответ:** «В модуле `auth.js` все записи индексируются по уникальному ключу `userId`. При переключении аккаунта загружается только прогресс, инвентарь и статистика текущей сессии. Пользователь А не может видеть или перезаписать данные пользователя Б.»
